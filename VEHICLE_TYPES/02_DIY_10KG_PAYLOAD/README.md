# B형 — 별도 가공 샤시 / 적재 10kg / 전륜조향 4WD

2026-09-15 R0. **부품 배치 검토본이며 구매 확정·가공 출도본이 아니다.** A형 파일은 수정하지 않는다. 이전 ARRMA 롤러 및 고정 총중량 25kg 검토를 대체하는 현재 B형이다.

## 현재 파일

- `TypeB_DIY_10kg_R0.FCStd`: 새 FreeCAD 문서. 부품별 선택 가능. 구매 후보는 속성의 CandidatePartNumber, DesignStatus, SourceURL로 추적한다.
- `TypeB_DIY_10kg_R0.step`: 교환용 조립 형상. FreeCAD 속성은 STEP에서 보존되지 않을 수 있으므로 원본 문서를 함께 사용한다.
- `Assembly.png`, `Chassis.png`: 전체 / 데크 제외 구조 보기.
- `build.FCMacro`: 재생성 소스. 기존 A형이나 구형 B형을 읽거나 덮어쓰지 않는다.
- `Layout_R0.svg`: 상면·측면의 잠정 치수와 부품 후보를 표시한 배치도.
- `BOM.csv`: 구매 후보 및 미확인 연결 규격.
- `calculations.json`: 질량 예산, 휠 회전수, 조향각 예시.

## 설계 기준

| 항목 | 이번 배치안 |
|---|---|
| 적재하중 | 10kg. 기체·배터리 무게 제외. 센서 등 적재물은 이 10kg 안에서 집계 |
| 구동 | 바퀴별 모터 4개, 각각 CV 구동축으로 연결 |
| 조향 | 전륜 기계식 조향, 후륜 비조향. 스키드 조향 아님 |

| 바퀴 | Ø160×60mm 공간 예약. 실제 제품 미선정 |

첨부 원본의 휠베이스450mm + 바퀴Ø180mm는 전체길이630mm가 되어 표기600mm와 모순된다. 새 모델은 휠베이스360+바퀴160=520mm로 맞춘다. 직진 외형 면적은 원본 표기600×450 대비 약15% 작다. 조향 때는 타이어의 회전 포락 때문에 폭이 늘어난다. 간단한 중심회전 가정의 30도 타이어 투영폭만으로도 전체폭 약512mm가 될 수 있으며, 실제 킹핀 오프셋 반영 전 수치다.

## 동력과 조향 연결

각 모터 → 전용 연결 어댑터 → Traxxas 8951 드라이브컵 후보 → 8950X CV 후보 → 8654 휠허브 → 바퀴.

앞바퀴는 CV의 각도 변화와 신축으로 조향·현가 운동을 수용한다. 모터는 샤시에 고정한다. 모터 축은 8mm REX이며 RC 드라이브컵에 바로 끼울 수 있다고 확인된 상태가 아니다. 보라색 어댑터는 연결 공간을 표시할 뿐, 가공 가능한 축/스플라인 도면이 아니다. 센터·전후 차동기어는 이 4모터 구조에 사용하지 않는다.

서보 → 벨크랭크/서보세이버 → 좌우 타이로드 → 전륜 너클. 주행 중 네 바퀴의 명령 회전수는 회전 반경에 따라 달라야 한다. R=1m(후륜축 중앙 기준), 휠베이스360/윤거380 예시에서 전륜 내측 약24도, 외측 약16.8도다. 이 값은 이론 목표이며 현재 링크 모델이 그 각도를 구현하도록 기구 해석된 것은 아니다.

## 구매 후보의 근거와 한계

ServoCity 5303-2402-0051은 제조사 STEP를 가져와 네 위치에 배치했다. [제조사 제품](https://www.servocity.com/5303-series-saturn-planetary-gear-motor-50-9-1-ratio-24mm-length-8mm-rex-shaft-360-rpm-3-3-5v-encoder/) / [규격서](https://www.servocity.com/content/spec_sheets/5303-2402-0051_spec-sheet.pdf). 24V, 50.9:1, 8mm REX 출력, 엔코더를 갖춘 후보. 정격토크는 약3.13Nm이고 그 조건의 회전수는295rpm이나 **정격 부하에서는 25% 운전/75% 휴지 제한**이 있다. 연속 운전 합격품으로 확정하지 않았다. 방수 IP 등급도 확인되지 않았다. 원본 STEP에는 배선과 내부 부품까지 포함된다.

현가/허브/조향 후보는 Maxx 일반 폭 부품군이다. [Traxxas 부품표](https://traxxas.com/media/productattach/C-89086-4/3/89086-4_parts_1.pdf) 및 아래 판매 페이지로 부품 존재와 판매 상태를 대조한다. 일반 폭 8929/8930/8950X와 WideMaxx 8998/8999/8996X를 혼용하지 않는다. 공개 부품도는 조립 관계와 부품 번호 확인에는 유용하지만, 피벗 좌표·베어링 좌석 간격·CV 신축량의 치수도는 아니다. **현재 주황색 RC 부품은 원본 형상이 아닌 공간 모델이다.** 이를 구매 부품의 정확한 3D 도면이라고 해석하면 안 된다.

- [8950X 판매 페이지](https://www.hubhobby.com/traxxas-8950x-driveshafts-steel-assembled.html): 열람 당시 In stock 표시. 국내 배송/최종 재고 미확인.
- [8930 판매 페이지](https://www.hubhobby.com/traxxas-8930-lower-suspension-arms-black.html): 검색에 판매 등록 확인, 상세 페이지 재고 확인 실패.
- [8946 판매 페이지](https://www.hubhobby.com/traxxas-8946-steering-bellcranks.html): 판매 등록 확인, 재고 미확인.
- [8961 판매 페이지](https://www.acshobbies.com/products/traxxas-8961): 판매 등록 확인, 재고 미확인. 스프링 별도.
- [8654A 제조사](https://traxxas.com/8654a-17-mm-orange-aluminum-splined-wheel-hubs-4): Maxx에서8950X 또는8996X 필요하다고 명시.
- [Traxxas 서보 가이드](https://traxxas.com/articles/servo-upgrade-guide): 2280은6V에서600oz-in급의 후보. 서보 혼/벨크랭크 연결과 실제 조향토크 검토 전이다.

## 상세 설계로 넘어가기 위한 미해결 항목

1. 일반 폭 암/너클의 실제 피벗 간격과 핀 규격을 확보해 현재 공간 모델을 교체. 제조사 도면 또는 실측 필요.
2. 8951 컵의 내경·핀 홈·고정 방식, 8950X 최소/최대 길이·최대 각도를 확보. 8REX 어댑터와 독립 지지 베어링 구성 확정. 현재는 신축/각도/허용토크 적합성 미판정.
3. 실제 타이어 SKU와 허브 오프셋 확정. 현가 끝 위치 및 최대 조향각의 간섭 검사 후 전체폭 확정.
4. 스프링 강성·프리로드·모션비 및 쇼크 최소/최대 길이 확인. 10kg 적재 시 차고·범프 여유 검증. 원본50mm 스트로크는 아직 달성값이 아니다.
5. 모터의 실제 부하/주행시간 열 검토와 방진방수 대책, 4채널 전류 제한·엔코더 제어기 선정.
6. 타이로드 길이, 애커먼 각, 범프스티어 계산 후 조향서보 토크·혼 길이 결정.
7. 위 연결 치수 확정 후 샤시 지지판의 구멍·공차·체결 나사 및 국부 강도 검토를 마쳐 가공도 출도.

현재 생성 검사는 형상 유효성과 파일 저장 확인에 한정한다. 조립 간섭, 부품 강도, 운동학, 피로, 실제 적재 성능 검증은 완료하지 않았다. **이번 결과로 일괄 구매하거나 샤시를 가공하지 않는다.**
