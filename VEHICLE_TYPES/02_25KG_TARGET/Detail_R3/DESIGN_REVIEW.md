# B형 R3 — 총중량25kg 목표 변경

대표 도면: TypeB_25kg_Detail_R3.FCStd. A형은 유지한다. 기존30kg 검토본은 사용자 요청으로 삭제했다.
차량·배터리15kg + 장비10kg = 총25kg은 질량 예산이다. CAD 실측 질량이나 제작품 무게를 확정한 값이 아니다.
속도0.1–2m/s, 평지, 외경145mm와 구조 치수는 유지한다. 구조를 무조건 얇게 만들지 않았다.

## 재계산 결과
- 바퀴당 평균 정적하중: 61.3125N (6.25kg 상당), 균등 배분 가정.
- 구동계 보수 가정(Crr0.1, 가속1m/s²): 견인력49.525N, 네 바퀴 합계3.591Nm.
- 조향 선별 토크: 7.946Nm. 마찰계수0.8, 스크럽40.5mm, 가정계수2. 접지면 비틀림과 링크 각도 미포함.
- 스프링 정적 힘: 77.682N, 압축9.033mm, 설치 길이90.967mm.
- 하강10mm에서 남는 압축1.196mm; 상승15mm에서 압축21.019mm.

## 도면 변경
스프링 설치 길이를 새 정적하중에 맞추고 상하 받침 위치도 조정했다. 이 변경은 같은 정적 현가 자세를 유지하기 위한 받침 조정안이며 자동으로25kg에서 해당 자세가 보장된다는 뜻은 아니다. 가이드 신축/조정 체결과 하강 제한장치는 아직 상세 설계가 필요하다.
프레임·축·허브 치수와 8Nm 축 검토 기준은 유지한다. 기존 구조 치수 유지가25kg 전체 구조 검증을 뜻하지 않는다.

## 미완료 항목
감속비48.895는 추가4:1 및 미확인11T를 포함한 가정이다. 모터 연속정격, 감속기·3개 차동기어·CV 연결, 조향 감속/타이로드, 댐퍼와 하강 제한 상세는 미확정이다.35kg·cm 서보 직접 구동안은25kg에서도 적합 판정하지 않는다.
스프링 강성 허용차와 실제 하중 편차를 고려하면 하강 시 여유가 작다. 하강10mm는 검토 범위이며 제조 허용치가 아니다. 실제 질량분포와 스프링 실측 후 받침/제한을 조정해야 한다.
