# C형 — 독립 구동 스윙암 4WD

현재 검토 주력은 C형입니다. A형 ZD9021-V3와 B형 RC 부품 조합은 유지하고, C형 완료 후 B형을 다시 검토합니다.

C형 기본안: 바퀴별 감속모터·하중지지 허브·스윙암·쇼크로 구성한 4륜 독립현가, 좌우 차동속도 조향. 전륜 서보 조향은 비교 대안으로만 남기고 이번 기본 모델에는 추가하지 않았습니다.
모터와 바퀴가 같은 스윙암에서 움직여 차체→바퀴 사이 긴 CV축을 생략합니다. 모터 출력축이 차중을 직접 지지한다고 가정하지 않고 별도 하중지지 허브 공간을 두었습니다.

- 외형540×440mm, 휠베이스360, 윤거380, 타이어Ø180×60, 데크320×280은 배치 가정입니다.
- 적재10kg 목표, 총중량 미정. 구조·하중·접지·회전 토크는 미검증입니다.
- 모터·감속기·허브·타이어·쇼크는 제품 미선정 공간모델입니다. 구매 확정 부품 형상으로 오인하지 마십시오.
- 직진속도0.1~2m/s 목표는 D180에서 약10.61~212.21rpm입니다.
- 차동속도 조향은 스키드 조향으로 타이어의 횡방향 미끄러짐이 발생합니다. 직진 저항 계산만으로 회전 토크를 확정하지 않습니다.
- 현가 피벗과 쇼크는 구조 설명이며 자유도 구속·운동학 해석·스트로크와 범프스톱·피로 검증 전입니다.
