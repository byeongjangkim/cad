# Type B — 조향 너클·구동축 기반 자체 샤시 차량

기준 파일: [TypeB_DIY_10kg_R2.FCStd](TypeB_DIY_10kg_R2.FCStd)
대표 이미지: [Preview.png](Preview.png)

자체 샤시에 RC 현가·허브 부품을 조합하는 4륜 독립현가·바퀴별 구동 차량이다. 전륜은 피벗볼 조향블록을 이용한 기계식 조향, 후륜은 하부암과 캠버 링크 구조다. 모터에서 CV/도그본 구동축, 액슬, 휠 헥스를 거쳐 바퀴로 동력을 전달한다. 트레일링암에 구동박스를 함께 싣는 C형과 구분한다. 적재 10kg는 설계 목표이지 검증된 능력이 아니다.

## 현재 설계 상태
R2를 기준으로 유지한다. R3는 간섭 탈락 이력이므로 기준본으로 사용하지 않는다. 구매 확정·제작 승인 모델이 아니다. 형상에는 공개 규격과 배치 가정이 함께 포함되어 있다. 연결 규격은 CAD 내부 `09 연결 규격표`를 참조한다.

모터·감속기와 출력 연결, 현가 피봇 위치, 베어링 간격과 휠 오프셋, CV 신축과 각도, 쇼크 및 조향 운동은 미확정이다. OEM 상세 형상, 조향·현가 전 구간 간섭, 하중·피로·체결 검증은 미완료다. 기존 정적 형상 검사 결과를 주행 검증으로 해석하지 않는다.

부품 연결 관계의 기존 근거: [ARRMA ARA10604 제조사 설명서](https://www.horizonhobby.com/on/demandware.static/-/Sites-horizon-master/default/dw759b6c42/Manuals/ARA10604-Manual-MULTI.pdf). 해당 차량 전체를 B형으로 채택했다는 뜻은 아니다.
