# Type C — 트레일링암·구동박스 기반 모듈

유일한 기준 CAD: [TypeC_G_RightAngle_R3.FCStd](TypeC_G_RightAngle_R3.FCStd)
유일한 대표 이미지: [TypeC_G_RightAngle_R3.png](TypeC_G_RightAngle_R3.png)

사용자가 보존하도록 지정한 피봇·트레일링암·코일오버·구동박스·휠 기본 모듈이다. 구동박스와 바퀴 지지부가 암과 함께 현가 운동하는 방향이다. B형의 조향 너클·구동축 기반 차량과 구분한다.

현재 남은 CAD는 바퀴 한 개의 모듈이며 완성 차량이 아니다. 샤시 형태와 연결부, 피봇 지지 방식, 코일오버 배치는 앞으로 구조의 모양부터 결정한다. 기존에 삭제한 샤시·타워·비교안을 확정 구조로 간주하지 않는다. 좌우 속도차 조향은 이전 검토 방향이며 이번 정리로 새로 확정하지 않는다.

제품·치수·체결·강도·운동 간섭을 확정하는 자료가 아니다. CAD 내부의 기존 제품명이나 선정 문구는 원본에 남아 있는 검토 이력이며 구매 확정을 뜻하지 않는다. 파일 내용은 보존한 원본과 동일하다.
