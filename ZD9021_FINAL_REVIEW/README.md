# ZD9021 통합 최종 검토본

최신 조건은 총중량30kg, 속도0.1–2m/s입니다. FreeCAD 파일 내부 최신 요구조건 표와 A3 배치도 주석에 반영했습니다.

- ZD9021_Integrated_Review.FCStd: 이 파일 하나를 열면 주행체·모터·ESC·상부 센서·배터리를 함께 볼 수 있습니다.
- ZD9021_Integrated_Review.step: 다른 CAD 프로그램용 통합 형상입니다.
- Drive_Layout_A3.pdf / .svg: 모터·ESC와 단순화한 샤시 기준 평면/측면 배치 검토도입니다. 전체 부품 가공도는 아닙니다.
- Platform.png / Drivetrain.png: 전체 조립체 및 구동계 미리보기입니다.
- SELECTION.md: 제품 선정 출처, 치수, 속도·토크 계산과 미검증 항목입니다.
- validation.json: 이번 저장 및 형상 검증 결과입니다. complete.txt는 저장 후 다시 열기까지 완료됐을 때 생성됩니다.

01 부품 원형,04 분해 배치,08 교체 전 배치는 숨겼습니다. 삭제하지 마세요.07 선정 구동계에서 모터·기어·ESC를 확인할 수 있습니다. 이전 버전은 각 폴더에 보존했습니다.

이 파일의 ‘최종’은 현재까지의 작업을 통합한 검토본이라는 의미입니다.30kg 허용하중, 저속부하/열 성능,실제 차축 감속비,속도 폐루프,기어 반대쪽 배치와 체결 치수는 미확인입니다. 실제 제작 승인 도면으로 사용하지 않습니다. 형상 유효성과 STEP 재읽기는 하중·동작 검증을 대신하지 않습니다.
