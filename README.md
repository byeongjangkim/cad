# UGV CAD — 현재 설계 기준

## 타입 구분
| 타입 | 개념 | 현재 범위 |
|---|---|---|
| [Type A](TYPE_A/README.md) | ZD9021-V3 기성 키트 기반 참조 차량 | 전체 차량·장비 배치 |
| [Type B](TYPE_B/README.md) | 조향 너클·구동축 기반 자체 샤시 차량 | R2 전체 차량 배치 |
| [Type C](TYPE_C/README.md) | 트레일링암·구동박스 기반 모듈 | 사용자 지정 단일 바퀴 기본 모듈 |

각 타입 폴더에는 기준 FreeCAD 1개, 대표 이미지 1개, 개념·현황 설명 1개만 둔다. 모양·연결 구조 검토와 상세 치수·제품 선정을 구분한다. 현재 모델은 제작 승인도면이 아니다.

## 파일 관리
- 이 폴더의 TYPE_A, TYPE_B, TYPE_C만 현재 작업 위치다.
- 이전 VEHICLE_TYPES, zd9021_v*, chassis_v01, ZD9021_FINAL_REVIEW 및 중복 검토·백업·STEP·생성 스크립트는 정리 대상이다.
- 원본 CAD 내용은 변경하지 않고 새 위치로 이전했다. STEP는 필요할 때 기준 CAD에서 내보낸다.
- FreeCAD에서 이전 경로 문서가 열려 있다면 저장하지 말고 닫은 뒤 새 위치의 문서를 연다. 이전 복구 항목은 복원하지 않는다.
- .git은 현재 최소 파일의 로컬 버전 관리용이다. 이번 정리는 원격 저장소에 게시하지 않는다.
