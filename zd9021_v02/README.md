# ZD 9021-V3 기반 오프로드 4WD 검측 플랫폼 — v02

인터넷의 공개 제품 치수, V3 키트에서 제공한 PIRATES3 매뉴얼, 차체 상세 사진을 반영한 **부품별 3D 배치 모델**입니다. 원본 제조 CAD의 복제본이나 가공 확정 도면은 아닙니다.

## 열기

- `ZD9021V3_assembly.FCStd`: 주행체 + 상부 데크를 표시한 플랫폼 조립.
- `ZD9021V3_chassis_view.FCStd`: 데크를 숨겨 하부 주행체를 확인하는 동일 모델.
- `ZD9021V3_rolling_chassis.step`: 주행체 조립 STEP.
- `ZD9021V3_platform.step`: 상부 데크를 포함한 플랫폼 STEP.
- `parts/`: 각각의 부품 원형 STEP 및 독립 FreeCAD 문서.
- `BOM.csv`: 부품번호·수량·치수 근거.
- `rolling_chassis.png`, `platform.png`, `exploded.png`, `top.png`, `side.png`: 뷰 이미지.

조립은 App::Link의 고정 위치 배치입니다. `02` 주행체, `03` 커스텀 데크, `04` 분해 배치를 선택하고 Space로 표시/숨김을 전환합니다. `01`은 원점 기준 부품 원형이므로 기본적으로 숨겨져 있습니다. 운동학 조인트는 없습니다.

## 반영한 사양

| 항목 | 적용값 |
|---|---|
| 기반 | ZD 9021-V3 / PIRATES3 부품 구성 |
| 섀시 8264 | 446×132×3, 끝 목 부분이 좁은 외곽 |
| 주행체 외곽 | 550×430, 길이에는 커스텀 보호 연장부 포함 |
| 휠베이스 / 섀시 지상고 | 370 / 65 |
| 타이어 / 휠 육각 | 145×69 / 17 |
| 현가 | 4륜 독립 상·하부 암 배치 |
| 쇼크 | 전8317·후8318, 외경25, 중심거리110/132 |
| 디퍼렌셜 | 센터8156 + 프론트8008 + 리어8008 |

기어박스 내부의 전후 디퍼렌셜은 기어박스 링크를 숨기면 볼 수 있습니다. 디퍼렌셜은 외형 조립체이며 치형과 내부 유성기어는 생략했습니다. 타이어도 상세 노브 대신 홈 형상의 외형 모델입니다. LiDAR·카메라·컴퓨터·배터리 셀·모터·ESC는 이번 차체 모델 범위에 포함하지 않았습니다. 자율주행/4WD의 소프트웨어나 기능 검증을 의미하지 않습니다.

## 근거와 수정

`SOURCES.md`에 출처·적용값·추정 범위를 기록했습니다. 각 부품의 FreeCAD Data 탭 `Provenance`에도 부품번호와 근거가 있습니다.

`dimensions.json`을 수정하고 FreeCAD 내장 Python으로 `build_zd9021.py`를 재실행하면 주요 외형이 재생성됩니다. `Dimensions` 스프레드시트는 **치수 기록표**이며 형상을 자동 구동하지 않습니다. 홀·외곽 세부점은 생성 스크립트에서 수정합니다. 생성 형상은 BREP이며 스케치 구속 이력이 없습니다. 조립 위치는 FreeCAD의 LinkPlacement로 직접 편집할 수 있습니다. 재생성은 수동 편집을 덮어쓰므로 편집본은 다른 파일로 저장하세요.

GUI 미리보기/색상/표시 상태는 `render_zd9021.FCMacro` 실행으로 저장합니다.

## 검증 범위

모든 부품의 유효 솔리드 검사, 조립 STEP 재읽기 시 솔리드 수 보존, 섀시·타이어 및 조립 외곽 치수 검사를 수행했습니다. 상세 결과는 `validation.json`입니다.

공개되지 않은 체결 홀 좌표·암 길이·조향 링크·장착 위치는 추정입니다. 현가 스트로크/조향 전 범위의 간섭, 강도, 기어 물림, 커스텀 데크의 ZD 섀시 체결은 검증하지 않았습니다. 실제 제조 전에는 해당 인터페이스를 실측/도면으로 확정해야 합니다.
